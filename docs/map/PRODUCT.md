# Map — product code

Start here for any code change. Find the area, then open only the files the task needs. Everything below ships to users, so this map lives outside those folders.

| Area | What lives there | Read before changing |
|---|---|---|
| [magepeople-yacht-booking-system.php](../../magepeople-yacht-booking-system.php) | Plugin header, version constants, autoloader, boot | [includes/Plugin.php](../../includes/Plugin.php) |
| [includes/Plugin.php](../../includes/Plugin.php) | Registers every service on `init`; the order things load in | — |
| [includes/Settings.php](../../includes/Settings.php) | The `mageyabo_settings` option: defaults, sanitising, getters | `assets/admin/src/routes/Settings.js` |
| [includes/Capabilities.php](../../includes/Capabilities.php) | The three plugin capabilities and `Capabilities::can()` | — |
| [includes/functions.php](../../includes/functions.php) | Global helpers: prices, dates, booking reference, confirmation URL, guest documents | — |
| `includes/Booking/` | Pricing (`PricingEngine`), availability and seats (`AvailabilityService`), repositories for bookings, guests, add-ons, coupons, pricing rules; built-in coupons (`CouponService`) | `PricingEngine.php` |
| `includes/Payments/` | Gateway registry (`Gateways`), Offline, PayPal, Stripe; WooCommerce: linked hidden products (`WooCommerceProduct`), cart and orders (`WooCommerceGateway`), checkout inside the drawer (`WooCommerceDrawer`) | `Gateways.php` |
| `includes/Rest/` | REST API under `mageyabo/v1`: yachts, quote, availability, bookings, guests, add-ons, coupons, pricing rules, settings, reports | `Controller.php` |
| `includes/Frontend/` | Shortcodes and the booking form and drawer markup (`Shortcode`), confirmation page, Gutenberg block, single-yacht template loader, newsletter | `Shortcode.php` |
| `includes/Notifications/` | Booking confirmation email and its tags (`BookingEmailer`) | — |
| `includes/PostTypes/`, `includes/Taxonomies/` | The yacht post type; yacht class and occasion taxonomies | — |
| `includes/Install/Migrator.php` | Custom tables, `MAGEYABO_DB_VERSION` migrations, pages created on activation | — |
| `includes/Cron/` | Daily maintenance (guest-data retention) | — |
| `includes/Admin/Menu.php` | The single admin page that hosts the React app | — |
| `assets/admin/src/` | React admin app: `App.js` (screens and nav), `router.js` (hash routing), `registry.js` (add-on routes and slots), `routes/` (one screen each), `components/`, `api/` | `registry.js` |
| `assets/frontend/src/` | Front-end scripts and styles: `booking-form.js` (form, drawer, coupon, WooCommerce stage, extension API, prefill from `ybs_type` / `ybs_date` / `ybs_guests` URL parameters), `search.js`, `yacht-list.js`, calendar, map, gallery; `block/` | `booking-form.js` |
| `assets/frontend/yacht-single.css`, `yacht-single.js` | The single-yacht page (not built by webpack) | [templates/single-yacht.php](../../templates/single-yacht.php) |
| `assets/frontend/embedded-checkout.css` | WooCommerce checkout and thank-you pages inside the drawer (not built) | `WooCommerceDrawer.php` |
| `assets/build/` | Generated by `npm run build`; never edit by hand | — |
| `templates/` | `single-yacht.php` (theme-overridable), `embedded-checkout.php` (bare checkout canvas) | — |
| `assets/demo/` | Photos for the sample fleet; the fleet data is `YachtsController::dummy_yacht_samples()` | — |

**Extension points** used by the Pro add-on and third parties: the PHP hooks named `mageyabo_*` (price components, quote, booking fields, booking created, status and payment changes, form extras, guest documents, admin routes, REST routes), `window.mageyaboBooking.registerFormExtension()` in `booking-form.js`, and `window.mageyaboAdmin.registerRoute()` / `registerSlot()` in `registry.js`. A change to one of these is a change to the Pro repository's contract: check its use there.
